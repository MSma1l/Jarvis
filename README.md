# Djarvis

Asistent personal cu conversație vocală completă, construit modular pentru a automatiza activități personale și operaționale în mod sigur. Djarvis primește comenzile și întrebările prin voce și răspunde tot prin voce; textul este un canal auxiliar pentru afișare, control și audit. Djarvis va porni fără dependență obligatorie de IA, iar capabilitățile IA vor fi adăugate ulterior ca extensii controlate.

## Obiectiv

Djarvis trebuie să poată primi comenzi prin voce sau text, să execute acțiuni autorizate și să trimită rezultatele într-un canal ușor de urmărit, inclusiv Telegram. Va fi proiectat pentru macOS, Windows, iPhone, iPad și Android, cu un VPS personal ca punct central pentru funcțiile la distanță.
